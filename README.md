# Planta de Reciclaje — React Native

App movil (Expo + TypeScript) para automatizar el flujo de una planta de reciclaje: bascula, clasificacion, stock de fardos y metricas.

- `main`: vacia a proposito.
- `week-XX`: una rama por semana; cada una sale de la anterior.
- Ver `HANDOFF.md` para el estado y los siguientes pasos.
- Ver `docs/` para la explicacion de cada semana.
